# Data cleaning decisions

Generated by `python -m data.clean`. Source: UCI Online Retail II (https://archive.ics.uci.edu/dataset/502/online+retail+ii), Dec 2009 - Dec 2011.

| Step | Rows | Reason |
|---|---:|---|
| Raw rows | 1,067,371 | Both sheets of the UCI file concatenated |
| Exact duplicate rows dropped | 34,335 | The two sheets overlap on 1-9 Dec 2010, and some invoices repeat identical lines |
| 'A' invoices dropped | 6 | Bad-debt accounting adjustments, not sales |
| Non-product stock codes dropped | 5,812 | Postage, fees, manual adjustments, gift vouchers and test codes |
| Zero/negative price rows dropped | 5,964 | Mostly stock write-offs ('damaged', 'lost') recorded as negative quantity at price 0 |
| Negative quantity on non-cancellation dropped | 0 | Residual stock adjustments |
| Cancellation rows kept and flagged | 17,914 | is_cancellation = true; quantity is negative. Cancellations are NOT returns |
| Rows with missing customer_id kept | 227,089 | Guest checkouts; fine for sales totals, excluded from customer tables |
| Clean transaction rows | 1,021,254 |  |

## Derived tables

- `products`: 4,741 rows. Description = most frequent description for the code (the raw data has several spellings per code). Category = first matching keyword rule in `data/clean.py` (simple and auditable, not a trained classifier). Includes 3 synthetic `INJ00x` SKUs whose descriptions contain prompt-injection payloads for adversarial testing.
- `customers`: 5,852 rows, from non-cancelled transactions with a customer_id.
- `stock_levels`: 4,741 rows. **Synthetic.** on_hand = recent weekly demand x U(0.3, 8) weeks of cover; reorder_point = weekly demand x (lead time in weeks + 1); lead time drawn from {7, 14, 21, 28} days; seed 42. 1,153 SKUs start below their reorder point.

## Semantics the agent must respect

- Revenue = `quantity * unit_price`. Net revenue includes cancellations (negative quantity); gross sales exclude them.
- A cancellation (invoice prefixed `C`) is an order reversal, not a customer return. The dataset has no returns table.
- The data ends on 2011-12-09; the agent treats that date as 'today'.
